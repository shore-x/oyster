# Statement 局部引用图 MVP

> 状态：当前 MVP 实现规格，不是长期产品原则
>
> 日期：2026-08-04
>
> 范围：定义知识浏览器当前如何展示一个 Statement 周围的引用结构；不引入新的知识关系、分类或持久状态。

## 1. 目标与边界

当前知识浏览器只提供单对象局部图，帮助用户从一个 Statement 出发理解附近引用结构并继续导航。这个界面选择可以根据真实使用结果替换，不限制知识层未来必须使用或不得使用某种图形表现。

Statement 正文中的 `[[canonical title]]` 仍是唯一关系来源。Projection 在当前知识视图上动态解析引用，默认截取中心节点无向最短距离两跳内的节点，同时保留每条引用的真实 `source → target` 事实。Store 不保存边、跳数、坐标、颜色或分组。

## 2. 当前展示机制

- 总览直接以文本标签的中心作为节点位置；不增加圆点锚点、箭头或可见节点背景；
- 图上的距离只用于表达当前局部引用结构，引用方向在悬浮预览中以自然语言说明；
- Renderer 临时把任一方向的引用视为一条无向连接，用于布局和相邻高亮；
- Renderer 移除中心节点后，对仍然相连的节点形成视觉簇，使同一分支靠近，并让组内边共享克制的颜色；文本保持清晰的中性色；
- Renderer 先按跳数和视觉簇生成稳定的径向初始位置，再使用文字标签的实际展示矩形消除重叠；空间不足时增加 Scene 高度，不缩小字体；
- 节点位置确定后，Renderer 把连线端点裁剪到文字安全边界；直线路径无遮挡时保持直线，穿过其他标签或与非相邻边交叉时才选择克制的 Bézier 曲线；
- 视觉簇只属于当前 Scene，不命名、不持久化，也不解释为内容类别或语义相似；
- 悬浮节点时只突出它和直接相邻节点，点击节点继续导航。

当前连通分支规则是有意保守的 MVP：它能避免把只有共同中心的星型叶子误标为同一组，但不能进一步拆分一个内部已有少量跨边的大连通分支。是否需要社区发现、共享邻居亲和度或其他布局机制，应先观察真实引用图再决定。

## 3. 验证

- Projection 单元测试覆盖两跳截取、方向事实、重复引用和未解析引用；
- Renderer 单元测试覆盖互相引用折叠为一条视觉边、星型结构不产生视觉簇、移除中心后相连的分支形成视觉簇，以及窄画布中的密集长标题避碰和冲突路径曲线化；
- Electron UI smoke 覆盖局部图存在、没有箭头或圆点、标签矩形不重叠、路径不穿过其他标签、端点位于文字安全边界、两跳节点可以导航且页面没有水平溢出。
