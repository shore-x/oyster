# Knowledge 局部引用图

Knowledge 浏览器提供以当前 Statement 为中心的局部引用图，帮助用户理解附近关系并继续导航。它是正文 wikilink 的可重建视图，不是第二份关系存储，也不增加 Relation、分类、坐标或视觉分组等领域概念。

当前体验优先展示与中心直接相关的内容，并按需披露更远邻居，避免完整知识图在阅读时制造噪声。引用方向仍来自正文；布局可以为了可读性暂时按双向邻接处理，但不能改写引用事实。

局部图的跳数、布局算法、尺寸、颜色、碰撞规则和交互测试属于 Renderer 实现。真实知识图证明当前表达不足时，可以替换可视化方式，而不需要迁移 Knowledge 数据。
